# Project Rules

Use ONLY:
- React
- React Router
- Context API
- Node.js
- Express.js
- MongoDB + Mongoose
- JWT Authentication

Do NOT use:
- Next.js
- TypeScript
- Redux
- Tailwind CSS
- GraphQL
- Prisma
- Docker
- Firebase
- Zustand
- Socket.io

Follow SWE381 course structure:
- controllers
- routes
- models
- middleware
- context
- pages
- components

Requirements:
- Follow the SWE381 lecture style
- Use functional React components only
- Use React Hooks only (useState, useEffect, useContext)
- Use CommonJS in backend (require/module.exports)
- Use REST API structure
- Use JWT for authentication
- Use Mongoose models and schemas
- Separate frontend and backend clearly
- Do not over-engineer the project
